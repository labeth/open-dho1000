# Spec appendices (tables)

Machine-readable interface tables referenced by spec 08. Tab-separated, first row is the header.
Like the specs, they are **UNVERIFIED** until checked on a unit.

| file | referenced by | contents |
|---|---|---|
| `keys.tsv` | 08 | key/encoder code, our symbolic id, hex, scan-matrix row/column, kind, panel label, `ug_item` = callout number in the DHO1000 User Guide front-panel figure (§4.4.1) |
| `leds.tsv` | 08 | LED row index → name, (group, bit) in the panel LED masks, meaning |
